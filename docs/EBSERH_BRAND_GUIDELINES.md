- **Main text**: Franklin Gothic BT

Myriad Pro → Arial → sans-serif

## 🏷️ Logo Usage Rules

### Minimum Size
- **Width**: 3 cm (≈ 85px at 72 DPI)
- **Never** reduce below this threshold

### Protection Area
- **Spacing**: 1.5× height of "HOSPITAIS UNIVERSITÁRIOS FEDERAIS"
- **Applied to**: All sides (top, bottom, left, right)
- **Rule**: No graphic elements within this zone

### Prohibited Alterations
- ❌ Changing colors
- ❌ Distorting proportions
- ❌ Adding effects (shadows, outlines, glows)
- ❌ Rearranging logo elements
- ❌ Modifying typeface

### Correct Usage
- ✅ Use official logo files (SVG, PNG)
- ✅ Maintain aspect ratio when scaling
- ✅ Respect color specifications exactly
- ✅ Ensure minimum size compliance
- ✅ Keep protection area clear

## 🤝 Institutional Signatures (Co-Branding)

### Sistema NPT Tri-Partite Branding

```
[UFC/HUWC Logo]  [X spacing]  [EBSERH Logo]  [X spacing]  [SUS Logo]
```

**Where**:
- `X` = Height of EBSERH letter 'E'
- All logos vertically center-aligned
- EBSERH logo ≤ 2× width of partner logos

### Horizontal Layout

```
┌───────────┐     ┌─────────────┐
│ UFC/HUWC  │  X  │   EBSERH    │
└───────────┘     └─────────────┘
```

### Vertical Layout

```
┌───────────┐
│ UFC/HUWC  │
└───────────┘
      ↓ X spacing
┌─────────────┐
│   EBSERH    │
└─────────────┘
```

### Government Co-Branding

```
┌─────────────┐  ┌──────────────────┐
│   EBSERH    │  │ GOVERNO FEDERAL  │
└─────────────┘  └──────────────────┘
```

**Reference**: www.secom.gov.br (Governo Federal manual)

## 💼 Application-Specific Guidelines

### 1. Business Cards (Cartão de Visita)

**Physical Specifications**:
- Size: **90mm × 50mm**
- Material: **Couchê 250g**
- Printing: **4×4 cores** (full color both sides)

**Front**:
- EBSERH logo + hospital identifier
- Green accent bar (#97bf29)

**Back**:
- Name font: **Gotham**
- Contact font: **Gadugi**
- Full contact information

**Digital Equivalent (Email Signatures)**:
- Include EBSERH logo (min 85px width)
- Green accent (#97bf29)
- Gadugi or Arial for text

---

### 2. Uniforms (Jalecos)

#### Left Shoulder

```
┌────────────────┐
│ HUWC Logo      │ ← 4.5cm × 4.0cm max
└────────────────┘
        ↓ 1X spacing
┌────────────────┐
│ EBSERH Logo    │ ← 7.0cm width
└────────────────┘
```

#### Right Shoulder

```
┌────────────────┐
│ SUS Logo       │ ← 6.0cm width
└────────────────┘
        ↓ 1X spacing
┌────────────────┐
│ Hospital ID    │ ← 4.5cm × 4.0cm max
└────────────────┘
```

**Notes**:
- 1X = height of EBSERH letter 'E'
- Centered on shoulder seam
- Embroidered or heat-transfer application

---

### 3. Vehicle Fleet (Frota)

#### Door Application
- **Logos**: Hospital + EBSERH
- **Position**: Centered
- **Avoid**: Door handle area

#### Rear Application
- **Logos**: Hospital + EBSERH (right-aligned)
- **Min Height**: EBSERH 10cm

#### Side Panels (Ambulances/Vans)
- **Logos**: Hospital + EBSERH + SUS
- **Alignment**: Horizontal
- **Min Height**: EBSERH 15cm

---

### 4. External Signage (Identificação Externa)

#### Standard Panel Proportions

```
         8X (total width)
┌─────────────────────────────┐
│                             │
│  [Logo] HOSPITAL NAME [EB]  │ ← 1X height
│                             │
└─────────────────────────────┘
```

**Where**:
- X = EBSERH logo height
- Total panel: **8X wide × 1X tall**

#### Layout Detail

```
[1/8X] [Hospital Logo] [1X] [Hospital Name] [1X] [EBSERH] [1/8X]
   ↑                                                          ↑
margin                                                    margin
```

**Margins**:
- Top/Bottom: **1/8X**
- Left/Right: **1/8X**
- Between elements: **1X**

**Font**: FrankGoth BT or Verdana Bold

#### Material Options
1. **Painted surface** (gray #9c9c9f background)
2. **Stainless steel** (brushed finish)
3. **Metal lettering** (individual 3D letters)

#### Illumination
- LED backlit (white or green)
- Spotlit (indirect lighting)

## 🌈 Color Backgrounds & Combinations

### Light Backgrounds (White, Light Gray, Pastels)
- ✅ Use **full-color EBSERH logo**
- ✅ Ensure **4.5:1 contrast ratio** (WCAG AA)

### Dark Backgrounds (Black, Navy, Dark Gray)
- ✅ Use **white version** (negative)
- ✅ Or full-color with **white buffer box**

### Multicolor Backgrounds (Photos, Patterns)
- ✅ Place logo on **solid white or gray box**
- ✅ Box must respect **1.5X protection area**
- ❌ Avoid busy imagery behind logo

### Single-Color Backgrounds
| Background Color | Logo Version |
|-----------------|--------------|
| Yellow | Gray logo (#9c9c9f) |
| Blue/Purple | White logo |
| Green | White logo (avoid brand green bg) |
| Red/Orange | White logo |

### 3. Button Styling (EBSERH Green Accent)

```css
.btn-primary {
  background-color: var(--ebserh-green);
  color: white;
  border: none;

  background-color: #7fa622; /* darker green */

  outline: 2px solid var(--ebserh-green);
  outline-offset: 2px;
}
```

```css

    --ebserh-gray: #000000;

    border-bottom: 2px solid black;
  }

    /* Switch to monocolor logo versions */

  }
}
```
